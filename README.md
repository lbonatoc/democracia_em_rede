# Democracia em Rede

Aplicação web para visualização e acompanhamento da atuação de representantes políticos.

## Sobre o projeto

O **Democracia em Rede** é uma ferramenta proposta como Trabalho de Conclusão de Curso do curso de Tecnologia em Sistemas para Internet do Instituto Federal de Educação, Ciência e Tecnologia de São Paulo (IFSP) - Câmpus São João da Boa Vista.

O projeto busca facilitar o acesso e a compreensão de dados parlamentares públicos por cidadãos não especialistas. Embora essas informações estejam disponíveis em diferentes portais e bases governamentais, muitas vezes são apresentadas de forma dispersa, fragmentada ou com linguagem técnico-institucional.

A aplicação pretende reunir e organizar essas informações em uma interface clara, acessível e intuitiva, contribuindo para o acompanhamento da atuação de representantes políticos e para a aproximação entre cidadãos, dados públicos e instituições democráticas.

## Objetivo

Projetar uma aplicação web voltada à integração, organização, visualização e interpretação de dados parlamentares públicos, facilitando o acompanhamento da atuação de representantes políticos.

Entre as funcionalidades previstas estão:

- consulta e busca de representantes políticos;
- visualização do perfil e de informações gerais dos parlamentares;
- organização dos dados por categorias;
- apresentação de proposições legislativas, votações e participação parlamentar;
- filtros e recursos de comparação;
- contextualização de termos legislativos;
- apresentação visual e sintetizada das informações;
- futura integração com fontes públicas, especialmente a API de Dados Abertos da Câmara dos Deputados.

## Estágio atual

O projeto encontra-se em fase de prototipação. Nesta etapa, o desenvolvimento está concentrado na construção das telas, nos fluxos de navegação e na experiência do usuário, utilizando dados simulados para representar as funcionalidades planejadas.

O backend, a persistência em banco de dados e a integração efetiva com APIs públicas não fazem parte do escopo inicial, mas poderão ser desenvolvidos futuramente para transformar o protótipo em uma aplicação completa.
